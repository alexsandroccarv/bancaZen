# Política de segurança

## Versões suportadas

Este é um repositório-modelo. Correções de segurança são aplicadas apenas à
versão mais recente da branch `main`.

## Como relatar uma vulnerabilidade

**Não abra uma issue pública** para relatar falhas de segurança.

Prefira o canal privado do GitHub:
**Security → Report a vulnerability** (GitHub Security Advisories) neste
repositório. Se não estiver disponível, entre em contato de forma privada com
o mantenedor pelo perfil indicado no `README.md`.

Ao relatar, inclua quando possível:

- descrição da falha e do impacto;
- passos para reproduzir (prova de conceito);
- versões/ambiente afetados.

Faremos o possível para responder o mais rápido possível e manter você
informado sobre a correção. Obrigado por divulgar de forma responsável.
