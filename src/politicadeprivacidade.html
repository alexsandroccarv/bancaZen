1. Como o TemplateZen funciona (sem servidor)

O TemplateZen roda inteiramente no seu navegador (client-side). Não há servidor, backend, banco de dados remoto ou API própria para onde suas informações sejam enviadas — nem cadastro, login ou senha.

As preferências (tema, alto contraste, tamanho de fonte, nome exibido no cabeçalho e tema selecionado) ficam no localStorage do navegador, associadas a este site.

3. O que o TemplateZen não faz

  • Não tem servidor, backend ou banco de dados próprio para onde seus dados sejam enviados.
  • Não pede conta, login, senha ou e-mail para uso.
  • Não usa publicidade, analytics ou pixels de redes sociais (por padrão).
  • Não vende, aluga, compartilha ou cede dados a terceiros.

4. Recursos de terceiros carregados pela página

Para exibir a interface, o navegador busca bibliotecas públicas de seus provedores originais:

  • Tailwind CSS (cdn.tailwindcss.com) — estilo visual.
  • Font Awesome (cdnjs.cloudflare.com) — ícones.
  • Google Fonts (fonts.googleapis.com) — fontes dos temas.

Essas requisições seguem o funcionamento normal da web: os provedores podem registrar metadados padrão de acesso (como endereço IP e navegador), segundo suas próprias políticas — o TemplateZen não envia dado adicional a eles. Se algum recurso não carregar, o app continua funcionando com um estilo mais simples.

5. Ações que saem do TemplateZen

Algumas funções levam informações para fora do app, sempre por sua iniciativa:

  • Doe um café: o QR code Pix é gerado consultando o serviço externo api.qrserver.com, que recebe apenas o código Pix “copia e cola” (dados do recebedor, não seus). A página também traz links de parceiros/afiliados — ao clicar, você sai do TemplateZen e passa a estar sujeito à política de cada site de destino.

6. Base legal (LGPD)

Como o processamento ocorre integralmente no seu dispositivo, sem coleta centralizada, esse uso se enquadra no tratamento realizado por pessoa natural para fins exclusivamente particulares (art. 4º, §1º, da LGPD). Ao usar serviços de terceiros (doar via Pix, links de parceiros), aplica-se a política de cada serviço.

7. Seus direitos como titular

O artigo 18 da LGPD garante acesso, correção, eliminação e portabilidade. Como tudo fica no seu navegador, você exerce esses direitos diretamente: para eliminar, apague os dados deste site no navegador; não há conta para cancelar nem servidor onde solicitar exclusão.

8. Alterações nesta política

Qualquer alteração fica registrada no histórico do repositório. A versão e a data no rodapé indicam a última atualização.

9. Contato

Dúvidas sobre esta política podem ser enviadas como uma issue no repositório do projeto.
