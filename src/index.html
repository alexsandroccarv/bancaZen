Este site é um modelo (template)

O que você está vendo — cabeçalho, abas, rodapé com tema claro/escuro, alto contraste e ajuste de fonte — não é o produto final de um projeto: é o ponto de partida reutilizável (templateZen) para montar novas aplicações web com essa mesma base pronta. Substitua este texto e as abas ao lado pelo conteúdo real do seu projeto.

Como usar este repositório como modelo no GitHub

  1. No repositório do GitHub, abra Settings e marque a opção Template repository (só precisa ser feito uma vez, pelo dono do repositório).
  2. Com isso ativado, o botão verde Use this template passa a aparecer no topo da página do repositório, ao lado de "Code".
  3. Clique em Use this template → Create a new repository, escolha o nome do novo projeto e crie-o — você recebe uma cópia limpa (sem o histórico de commits deste repositório).
  4. Clone o novo repositório e edite src/js/config.js com os dados do seu projeto (nome, autor, links, licença).
  5. Configure a publicação automática via SSH seguindo o DEPLOY.md, e ajuste CLAUDE.md, CHANGELOG.md e VERSION conforme o projeto evoluir.

Prefere não usar "Use this template"? Também funciona clonar o repositório normalmente ou baixar o ZIP — o README.md tem o passo a passo completo de customização.

Aparece no cabeçalho, ao lado do nome do aplicativo.
